# OnlyFans Mass-DM Automation — DirtyDialogues API Example

A minimal, developer-friendly **example integration** for **mass DM
automation**: send a **targeted mass-DM campaign to fans** through the
**DirtyDialogues** chatting / mass-DM API.

If you've been looking for an **"onlyfans mass message bot"**, this is the
API-based alternative aimed at builders and OnlyFans management agencies — one
small, readable file that shows the real request pattern instead of a brittle
browser script.

## What you get

- A single-file Node.js example that sends a targeted mass-DM campaign.
- API key loaded from the environment (`API_KEY`, `BASE_URL`).
- Clearly-marked **placeholder** endpoint and payloads — swap in the live values
  from the docs.

## Get started

1. **Get an API key** — required to run the example:
   **[dirtydialogues.com](https://dirtydialogues.com)**
2. Clone the repo, `npm install`, and copy `.env.example` to `.env`.
3. Run `node send-mass-dm.js`.

Full walkthrough is in the [README](https://github.com/your-org/onlyfans-mass-dm-automation-example#readme).

## Honest scope

This is an **example** integration to illustrate the DirtyDialogues messaging
API request flow. Endpoint paths and response schemas shown in the code are
**placeholders** — the authoritative, live reference lives in DirtyDialogues.

- **Live API docs:** [dirtydialogues.com/docs](https://dirtydialogues.com)
- **Sign up / get your API key:** [dirtydialogues.com](https://dirtydialogues.com)
